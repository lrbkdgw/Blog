这是一个**完全静态**的个人博客：页面托管在 GitHub Pages / Cloudflare Pages 上，没有服务器、没有数据库，但依然可以在线写作、发布和评论。本页就是这个站的使用说明。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 📝 在线编辑 | 分栏实时预览、工具栏、快捷键、滚动同步、自动保存草稿 |
| 🧮 KaTeX 公式 | 行内 `$…$` 与独立 `$$…$$`，支持 `aligned`、矩阵、分段函数 |
| 🎨 深色模式 | 跟随系统 / 手动固定，切换时平滑过渡 |
| 🔐 双模式登录 | 站点密码（写本地草稿）+ GitHub OAuth（发布到仓库，**推荐**） |
| 🚀 一键发布 | 浏览器直接调用 GitHub API 提交 Markdown，Actions 自动部署 |
| 💬 评论 | 登录后即可在文章下评论；连接 GitHub 的评论会公开保存在仓库里 |
| 🖌️ 个性化 | 主题、**多字体栈**、背景颜色——访客也能设置并保存在本浏览器 |
| 🔍 全文搜索 | <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>K</kbd> 唤起，支持方向键选择 |
| 🏷️ 标签 / 归档 | 标签云、按年归档、置顶、草稿、阅读时长、自动目录 |

## 快速上手

### 我是访客

1. 随便逛：[首页](/) 看最新文章，[归档](/archive) 按时间翻，[标签](/tags) 按主题找。
2. 想讲究点阅读体验：右上角 **个性化设置** ⚙ 里可以换主题、设置**多个字体**（按优先级依次尝试）、调背景颜色。无需登录，设置保存在你自己的浏览器里。
3. 想说两句：登录后就能在文章底部**评论**；未登录时也可以先读别人发表的评论。

### 我是作者

1. 打开 [登录页](/login)，**推荐直接用 GitHub 登录**（排在第一个）：点按钮 → 验证码会**自动复制** → 在 GitHub 页面粘贴并授权 → 完成。密码登录只能写本地草稿。
2. 进 **内容管理 → 写新文章**。草稿每 2.5 秒自动保存在浏览器，手动保存按 <kbd>⌘</kbd>/<kbd>Ctrl</kbd>+<kbd>S</kbd>。
3. 点 **发布到 GitHub**，文章会被提交回仓库，GitHub Actions 自动重新部署，约 1–2 分钟生效。
4. 内容管理里每篇文章都会标注 **已发布 / 仓库草稿 / 本地草稿**，并显示**上次发布到 GitHub 的时间**；同名的仓库文章和本地草稿会分两行显示，互不干扰。

## Markdown 语法

支持标准 Markdown、GFM（表格、任务列表、删除线）、代码高亮和 KaTeX 公式，另外还支持两种扩展语法。

### 折叠框

用 `::::类型[标题]` 开始、`::::` 结束，类型可以是 `info` / `success` / `warning` / `error`，标题后加 `{open}` 表示默认展开，标题里还能写公式：

```text
::::info[我是标题]
大家好，我是折叠框里的内容，支持 **完整 Markdown**。
::::

::::warning[$$\sum_{i=1}^n i$$ 也很美]{open}
默认展开的警告框。
::::
```

实际效果：

::::info[我是标题]
大家好，我是折叠框里的内容，支持 **完整 Markdown**。
::::

::::success[默认展开的提示]
标题后面写上 `{open}`，页面打开时就是展开状态。
::::

### 表格合并

单元格内只写一个 `^` 表示**与上方单元格合并**，只写一个 `<` 表示**与左侧单元格合并**：

```text
| 名称 | 数值 1 | 数值 2 | 备注 |
| :-: | :-: | :-: | :-: |
| A | 大 | 相同 | 无 |
| B | ^ | ^ | 无 |
| C | 跨两列 | < | 无 |
```

实际效果：

| 名称 | 数值 1 | 数值 2 | 备注 |
| :-: | :-: | :-: | :-: |
| A | 大 | 相同 | 无 |
| B | ^ | ^ | 无 |
| C | 跨两列 | < | 无 |

## 评论是怎么实现的

站是静态的，评论依赖仓库存储：

- **连接 GitHub 的用户**：评论以 JSON 文件提交到仓库 `content/comments/` 目录，所有人打开文章就能实时看到，不需要等重新部署。
- **仅密码登录**：评论保存在当前浏览器，只有自己看得到（想公开请连接 GitHub）。
- **未登录的访客**：可以阅读所有仓库评论，登录后即可参与。

## 常见问题

**草稿存在哪？**
浏览器 localStorage 里，换浏览器/清数据就没了；重要内容请及时发布或到「设置 → 本地数据」导出 `.md`。

**发布后要等多久？**
一般 1–2 分钟。如果发布完马上在旧页面里点来点去遇到「卡死」，刷新一次即可（站点已内置自动刷新机制）。

**字体云端加载失败？**
云端字体走 Google Fonts，网络不可达时会自动使用字体栈里的下一个字体，最后回退系统默认字体。
