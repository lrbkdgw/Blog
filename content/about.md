这里是本博客的完整使用手册：从阅读、搜索、评论、设置，到在线写作、GitHub 发布，以及本站支持的全部 Markdown 语法。阅读时可使用右侧目录快速跳转。

> 本站是静态博客：公开文章随站点构建发布；草稿、个人偏好与登录会话默认保存在当前浏览器。涉及 GitHub 的发布、图片上传与账号同步，需要先完成 GitHub 授权。

## 阅读、导航与搜索

### 浏览文章

- **首页**展示公开文章；置顶文章优先显示。文章卡片会显示日期、标签、字数和预计阅读时间。
- **归档**按年份浏览文章；**标签**页可按标签筛选。
- 文章页会根据二到四级标题自动生成**目录**；点击标题旁的链接图标可复制该小节锚点。
- 文章页标题下显示**作者**（未填写时使用站点作者）、更新时间、标签与预计阅读时间。
- 文章页提供「复制链接」、回到顶部按钮，以及相邻文章导航。带有 GitHub 仓库版本的文章还可打开「历史」。

### 全文搜索

按 <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>K</kbd>，或在非输入框区域按 <kbd>/</kbd> 打开搜索。搜索会匹配公开文章的标题、摘要、标签和正文；使用 <kbd>↑</kbd>/<kbd>↓</kbd> 选择结果，按 <kbd>Enter</kbd> 打开，<kbd>Esc</kbd> 关闭。

### 历史版本

发布到 GitHub 的文章，每次更新都会成为一个 Git commit。文章页「**历史**」按钮会列出该 Markdown 文件的历史版本：

1. 选择一个版本即可在站内查看当时的内容。
2. 在历史版本点击「编辑」时，如果现有文章与该版本完全一致，会进入对应编辑页。
3. 如果没有完全相同的文章，会创建一篇已预填该历史内容的本地草稿，避免覆盖当前版本。

#### 版本对比

历史版本面板右上角的「**版本对比**」按钮可以任意挑选一个**原始版本**和一个**新版本**，逐行对比两者的 Markdown 源码：

- 绿色为新增行，红色为删除行，左右两列分别是原始版本与新版本的行号。
- 顶部统计新增 / 删除的行数，「交换」按钮可快速反向对比。
- 默认只展示差异附近的内容，取消勾选即可查看完整源码。

## 登录、评论与账号

### GitHub 授权

在「登录」或「设置」中选择 GitHub 授权。本站使用 GitHub Device Flow：浏览器会打开 GitHub 验证页面，输入页面给出的设备码并确认授权即可。访问令牌只保存在当前浏览器，可在 GitHub 的授权管理页随时撤销。

### 评论

文章底部的评论区需要登录 GitHub 后才能发言。评论支持与文章相同的常用 Markdown、公式与代码预览；评论会保存在浏览器本地。登录用户可以删除自己的评论，站长可以管理所有评论。

## 写文章与管理内容

### 新建、保存与预览

访问「写文章」即可进入编辑器，未登录也能写作并保存本地草稿。

- 使用「仅编辑 / 双栏 / 仅预览」切换工作区；双栏模式会同步滚动位置。
- 停止输入约 2.5 秒后会自动保存；点击「保存草稿」或按 <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd> 可立即保存。
- 点击下载按钮可导出当前文章为 `.md` 文件。
- 在「文章信息」中设置标题、slug、日期、标签、封面、摘要、草稿与置顶状态。摘要留空时会从正文自动提取。
- 图片按钮会将本地图片上传到 GitHub 仓库的 `public/uploads/`，并自动插入图片 Markdown；此操作需要 GitHub 授权。

### 编辑器快捷键与工具栏

| 快捷键 | 作用 |
| :--- | :--- |
| <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd> | 保存本地草稿 |
| <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>B</kbd> | 粗体 |
| <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>I</kbd> | 斜体 |
| <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>K</kbd> | 插入链接 |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | 缩进 / 反缩进 |
| <kbd>Enter</kbd> | 在列表中续写；空列表项会结束列表 |

工具栏还可快速插入标题、引用、列表、链接、代码块、公式、Tuack 表格和交互展示框模板。

### 发布、投稿与审核

1. **拥有目标仓库写权限的用户**可直接将文章提交到配置的分支，随后由 GitHub Actions 构建部署。
2. **没有写权限的 GitHub 用户**点击「申请发表 (PR)」后，系统会创建分支或 Fork，并向目标仓库提交 Pull Request。
3. 仓库管理员可在「内容管理 → 发表申请」查看、合并或关闭投稿 PR。
4. 内容管理页可搜索、筛选、编辑、发布或删除本地草稿和仓库文章。

### 带密码的加密文章

目标仓库**管理员**在编辑器的「文章信息」中，可勾选「发布为带密码的加密文章」。发布前需两次输入同一密码：完整 frontmatter 和正文会在浏览器内使用 PBKDF2-SHA-256 与 AES-256-GCM 加密后才提交到 GitHub。

- 阅读、查看历史版本或再次编辑加密文章时都需要密码。
- 密码不会写入 GitHub、URL 或浏览器本地存储；忘记密码无法恢复正文。
- 已解锁的加密文章不会自动写成明文本地草稿。

## 设置与本地数据

### 外观与个人偏好

- 点击导航栏的太阳/月亮按钮切换深浅色主题；未手动选择时会跟随系统。
- 设置页可添加多个字体并调整优先级；浏览器会按顺序回退。支持手动输入、本机字体读取与 Google Fonts 尝试加载。
- 可选择背景色并调整渐变强度；100% 强度会以不透明背景覆盖页面。
- 字体和背景偏好使用浏览器本地存储，并会在其他打开的标签页中同步更新。完成 GitHub 授权后，可额外保存并恢复同一 GitHub 账号的偏好。

### 仓库与草稿

设置页的「目标仓库」用于配置 GitHub 用户/组织、仓库、分支和文章目录。它影响直接发布、PR 投稿、图片上传和文章历史读取。

本地草稿保存在当前浏览器：可在设置页导出全部草稿，或清空草稿。清除浏览器站点数据也会清除草稿、评论和未同步的个人偏好，因此重要文章请及时导出或发布。

# Markdown 写作语法

本站支持 CommonMark、GitHub Flavored Markdown（GFM）、KaTeX，以及下文说明的扩展指令。代码围栏中的内容只会原样显示，不会被扩展语法执行，适合编写教程。

## 文章头信息（Frontmatter）

文章文件顶部可用 YAML frontmatter 设置元数据：

```yaml
---
title: "文章标题"
date: "2026-10-04"
updated: "2026-10-05"       # 可选
summary: "文章摘要"           # 可选；留空时自动截取正文
tags: ["数学", "前端"]
cover: "https://example.com/cover.jpg"  # 可选
draft: false                  # true 时不显示在公开列表
pinned: false                 # true 时置顶
author: "作者名"              # 可选
---
```

文件名默认就是 URL slug，例如 `content/posts/hello.md` 对应 `/posts/hello`。编辑器内也可以直接修改 slug。

## 常用 Markdown

### 标题、段落、强调与分隔线

```markdown
# 一级标题
## 二级标题
### 三级标题

普通段落中的 **粗体**、*斜体*、***粗斜体***、~~删除线~~ 和 `行内代码`。

---
```

二到四级标题会自动加入文章目录。相邻的普通文本行属于同一段；空行可开始新段落。

### 列表与任务列表

```markdown
- 无序项目
  - 缩进子项目
- [ ] 未完成任务
- [x] 已完成任务

1. 有序项目
2. 第二项
```

### 链接、图片、引用与代码

````markdown
[链接文字](https://example.com "可选标题")
![图片替代文字](https://example.com/image.png)

> 这是一段引用。
> 可以写成多行。

`const value = 1`

```ts
const hello = (name: string) => `你好，${name}`
```
````

外部链接会在新标签页打开；代码块会自动高亮并提供复制按钮。编辑器上传图片后会自动插入图片写法。

### 表格

```markdown
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| A | B | C |
```

表格支持 GFM 对齐写法。单元格中也可以写强调、链接、行内代码和公式。

### 换行、转义、自动链接与脚注

```markdown
第一行末尾加两个空格（以 `␠␠` 表示）即可在同一段落内换行。

\*这不是斜体\*；反斜杠可转义 Markdown 符号。

<https://example.com> 会自动成为链接。

这是带脚注的文字。[^note]

[^note]: 脚注内容可以写在文章的任意位置。
```

## 数学公式（KaTeX）

行内公式使用一个美元符号，独立公式使用两个美元符号：

```markdown
行内公式：$E = mc^2$。

$$
\int_{-\infty}^{\infty} e^{-x^2}\,\mathrm{d}x = \sqrt{\pi}
$$
```

KaTeX 支持 `aligned`、矩阵、分段函数等常用 LaTeX 环境：

```markdown
$$
\begin{aligned}
(a+b)^2 &= a^2 + 2ab + b^2 \\
\operatorname{ReLU}(x) &= \begin{cases}x, & x>0 \\ 0, & x\le 0\end{cases}
\end{aligned}
$$
```

## 扩展 Markdown 语法

### 合并单元格表格

在表格中，让一个单元格的内容**仅为** `^` 可与上方单元格合并；内容仅为 `<` 可与左侧单元格合并：

```markdown
| 测试编号 | 数据范围 | 特殊性质 |
| :---: | :---: | :---: |
| 1 | $n \le 10$ | 无 |
| 2 | ^ | 无 |
| 3 | 跨列合并示例 | < |
```

### Tuack 风格表格

在表格前单独写一行 `::cute-table{tuack}`，即可渲染为三线表风格：

```markdown
::cute-table{tuack}

| 测试点 | 规模限制 | 状态 |
| :-: | :-: | :-: |
| #1 | $n \le 10^3$ | AC |
| #2 | $n \le 10^5$ | AC |
```

### 折叠提示框（Callout）

提示框由至少三个冒号开始和结束。类型可选 `info`、`note`、`tip`、`success`、`warning`、`error` 或 `danger`；标题放在 `[]`，加上 `{open}` 可默认展开：

```markdown
:::info[提示标题]{open}
提示框内容支持 **Markdown**、公式和代码。
:::

:::warning[注意]
请先保存草稿。
:::
```

提示框可以嵌套。内层请使用更多冒号，并用不少于开启数量的冒号关闭：

```markdown
:::info[外层]{open}
外层内容。

::::success[内层]
内层内容。
::::
:::
```

### 交互展示框

展示框由 `::show_begin{标题}{变量定义}` 与 `::show_end` 包围。框内可写普通 Markdown、KaTeX、`*&show()*&`、`*&hs()*&` 和映射；变量控件会显示在展示框下方。

```markdown
::show_begin{标题}{变量1; 变量2}
内容
::show_end
```

#### 变量定义：`Z`、`Q`、`S`

变量之间使用分号或逗号分隔。推荐用以下简写：

| 简写 | 类型 | 标准别名 | 定义示例 | 控件 |
| :---: | :--- | :--- | :--- | :--- |
| `Z` | 整数 | `integer`、`int`、`整数` | `n:Z=2[-5,5,1]` | 数字输入框 + 滑动条 |
| `Q` | 有理数 | `rational`、`number`、`float`、`有理数` | `p:Q=0.5[-2,2,0.25]` | 数字输入框 |
| `S` | 字符串 | `string`、`text`、`字符串` | `name:S=Starlog[0,12]` | 文本输入框 |

数值变量中，方括号依次表示 `[最小值, 最大值, 步长]`；字符串中表示 `[最小长度, 最大长度]`。默认值应使用十进制数字或普通文本。

#### 为有理数启用滑动条：`{faster_set}`

`Q` 默认只提供数字输入框。若需要同时提供滑动条，在该有理数变量定义的末尾添加 `{faster_set}`：

```markdown
p:Q=0.5[-2,2,0.25]{faster_set}
```

也可写在类型后，例如 `p:Q{faster_set}=0.5[-2,2,0.25]`。滑动条使用定义的最小值、最大值和步长。

#### 展示占位符与映射

| 写法 | 作用 |
| :--- | :--- |
| `*&show(变量名)*&` | 显示当前变量值 |
| `*&hs(表达式)*&` | 计算只含数值变量、`+ - * / ^ ()` 的表达式 |
| `*&变量名:{键1,内容1;键2,内容2}*&` | 建立变量值到显示内容的映射；映射优先替换内容 |

映射使用的变量若未在标题中声明，会自动创建对应控件；数值键会推断为数值变量，文本键会推断为字符串变量。

> 这三种写法都等价于**在源码中把该片段直接替换为对应的值或字符串**，再按 Markdown 渲染：结果不会被包进代码框，因此可以直接写在正文、表格、公式甚至代码块里。

完整示例：

::show_begin{二次函数小实验}{a:Z=1[-2,2,1]; b:Q=0.5[-2,2,0.25]{faster_set}; name:S=Starlog[0,12]}
你好，*&show(name)*&！当前 $a$ 为 *&show(a)*&、$b$ 为 *&show(b)*&，因此 $a^2+b$ 的值为 *&hs(a^2+b)*&。

$a$ 的文字映射：*&a:{-2,很小;-1,负一;0,零;1,正一;2,很大}*&
::show_end

对应源码：

```markdown
::show_begin{二次函数小实验}{a:Z=1[-2,2,1]; b:Q=0.5[-2,2,0.25]{faster_set}; name:S=Starlog[0,12]}
你好，*&show(name)*&！当前 $a$ 为 *&show(a)*&、$b$ 为 *&show(b)*&，因此 $a^2+b$ 的值为 *&hs(a^2+b)*&。

$a$ 的文字映射：*&a:{-2,很小;-1,负一;0,零;1,正一;2,很大}*&
::show_end
```

## 常见问题

:::info[发布后为什么没有立刻更新？]
GitHub Actions 构建与静态站点部署通常需要 1–2 分钟。可在仓库 Actions 页面查看部署状态。
:::

:::info[本地草稿会丢失吗？]
草稿依赖浏览器 localStorage。请在设置页定期导出，或发布到 GitHub；清除浏览器站点数据会删除本地草稿。
:::

:::info[为什么加密文章无法找回？]
加密密码不会上传或保存。请自行保管密码；没有正确密码，任何人（包括站点维护者）都无法解密正文。
:::
