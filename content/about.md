## 欢迎使用星野笔记 (Starlog)

**星野笔记 · Starlog** 是一个完全托管在 **GitHub Pages** 上的现代化静态博客系统。它无需独立后端服务器与数据库，却拥有完整的在线撰写、实时预览、公式渲染、评论互动与 GitHub 自动部署能力。

## ✍️ 文章创作与发表流程

本站支持两种发表机制，兼顾安全性与开放协作：

### 1. 仓库管理员直接发布
- 在 `/login` 页面使用 GitHub 账号登录。
- 若具备目标仓库的写权限，在编辑器中点击「**发布到 GitHub**」，系统将直接把 Markdown 文件提交至仓库的 `content/posts/` 目录并触发 GitHub Actions 自动构建部署。

### 2. 协作者与访客发表申请（PR 投稿）
- 任何 GitHub 登录用户即使没有仓库权限，也可以在站内撰写文章并点击「**申请发表 (PR)**」。
- 系统将自动在用户的 Fork 仓库中创建分支并向主仓库发起 Pull Request。
- 仓库管理员可在「**内容管理 → 发表申请**」中一键审批并合并 PR，合并后文章将自动上线！

## 📊 Markdown 进阶语法指南

本站解析器支持标准 CommonMark、GFM 以及洛谷扩展语法规范：

### 1. 表格单元格合并
在表格中，单元格内容为单独的 `^` 表示**向上合并**，为单独的 `<` 表示**向左合并**：

```markdown
| 测试编号 | 数据范围 | 特殊性质 |
| :---: | :---: | :---: |
| 1 | $\le 10$ | 无 |
| 2 | ^ | 无 |
| 3 | 跨列合并示例 | < |
```

### 2. Tuack 风格表格 (`::cute-table{tuack}`)
在表格前加入 `::cute-table{tuack}` 指令，即可呈现紧凑对齐的方边网格表格：

::cute-table{tuack}

| 测试点 | 规模限制 | 时间限制 | 状态 |
| :-: | :-: | :-: | :-: |
| #1 ~ #5 | $n \le 10^3$ | 1.0s | AC |
| #6 ~ #10 | $n \le 10^5$ | ^ | AC |
| 总结 | 10 个测试点已全部通过 | < | 满分 |

### 3. 折叠提示框 (Callouts)
使用 `:::info[标题]{open}`、`:::success`、`:::warning`、`:::error` 创建折叠信息块（标题支持 LaTeX 公式）：

::::info[点击展开查看详情]
折叠框可以用于隐藏长篇代码、证明过程或解题思路。
::::

::::success[$$\displaystyle\lim_{x \to 0} \frac{\sin x}{x} = 1$$]{open}
使用 `{open}` 参数可以使折叠框默认处于展开状态。
::::

::::warning[注意事项]
请在公共设备使用完毕后及时退出登录，以保护个人令牌安全。
::::

## 🎨 个性化定制

点击导航栏顶部的「**设置**」图标，访客与登录用户均可进行个性化调整：

1. **多字体优先级**：添加多个字体（如霞鹜文楷、PingFang SC、Fira Code），浏览器将按从前到后的优先级依次尝试匹配。
2. **背景渐变**：自定义色调与强度。当强度设为 100% 时，将呈现全屏不透明渐变效果。
3. **深浅色主题**：支持浅色、深色模式及系统跟随。

## 💡 常见问题 (FAQ)

::::info[文章提交后多久可以显示在网站上？]
GitHub Actions 构建与静态页面部署通常需要 1 到 2 分钟。部署完成后刷新首页即可看到最新内容。
::::

::::info[本地草稿会丢失吗？]
未发布的草稿保存在当前浏览器的 `localStorage` 中。建议定期在「设置 → 本地数据管理」中点击「导出全部草稿」备份为 `.md` 文件。
::::

::::info[如何参与文章讨论？]
在任何已发布的文章底部均设有评论区。使用 GitHub 账号登录后即可发表评论畅所欲言。
::::
