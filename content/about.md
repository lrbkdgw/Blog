## 欢迎来到星野笔记

星野笔记（Starlog）是一个托管在 GitHub Pages 上的静态博客，也是一套可以直接 Fork 使用的开源写作工具。它把**阅读、Markdown 写作、预览和发布**放进同一个轻量网站里：无需自建服务器或数据库，文章始终以普通 Markdown 文件保存在 GitHub 仓库中。

## 读者可以做什么

- 🔍 使用全文搜索、标签与归档快速找到文章
- 🧮 阅读 KaTeX 数学公式、语法高亮代码和 GFM 表格
- 📊 使用 `^`、`<` 合并表格单元格，使用折叠提示框组织长内容
- 💬 登录 GitHub 后参与文章评论
- 🎨 切换深浅主题，并在「设置」中保存背景和多级字体偏好
- 📱 在手机、平板或桌面设备上舒适阅读

## 作者工作流

1. 使用 GitHub OAuth 或站点密码登录。
2. 在分栏编辑器中书写 Markdown，并实时预览最终效果。
3. 草稿自动保存在当前浏览器，也可以随时导出。
4. 连接 GitHub 后一键发布，提交会触发站点自动部署。
5. 在内容管理页分别查看本地草稿和已发布版本，以及最近发布时间。

## Markdown 扩展

除了标准 Markdown、GFM、KaTeX 与代码高亮，本站还支持以下扩展。

### 合并表格

单元格只填写 `^` 会与上方单元格合并，只填写 `<` 会与左侧单元格合并：

| 项目 | 基础版 | 专业版 |
| :--- | :---: | :---: |
| Markdown | 支持 | 支持 |
| 数学公式 | ^ | 支持 |
| 在线发布 | 跨列支持 | < |

### 折叠提示框

使用 `:::info[标题]`、`:::success`、`:::warning` 或 `:::error` 创建折叠框；添加 `{open}` 可默认展开。

:::info[为什么选择静态博客？]{open}
静态页面速度快、维护成本低；Git 历史同时提供了天然的版本管理和备份。
:::

## 技术与数据

| 层面 | 选型 |
| --- | --- |
| 前端 | React 19 + TypeScript + Vite |
| 样式 | Tailwind CSS |
| 内容 | Markdown + remark / rehype + KaTeX |
| 存储 | GitHub 仓库 + 浏览器 localStorage |
| 登录 | GitHub OAuth Device Flow / 本地密码 |
| 部署 | GitHub Actions 或 Cloudflare Pages |

文章、评论入口和账号外观偏好都使用公开、可迁移的 GitHub 数据；本地草稿与访客外观偏好只保存在当前浏览器中。授权令牌不会发送到本站服务器，仅用于直接请求 GitHub API。

## 开始使用

- 想阅读内容：从首页、归档或标签页开始。
- 想调整阅读体验：打开「设置」，访客也可以保存字体与背景偏好。
- 想参与讨论：使用 GitHub 登录后，在文章底部发表评论。
- 想搭建同款网站：访问项目 GitHub 仓库，按照 README 的快速开始与部署指南操作。
