### 选拔赛 R1

:::info[A | 下标]

## 题目描述

给定一个长度为 $n$ 的序列 $a$，求一对满足 $i<j$ 且 $a_i<a_j$ 的 $(i,j)$ 使得 $j-i$ 最大。

## 输入格式

第一行：一个整数 $n$。

接下来一行：$n$ 个整数 $a_i$。

## 输出格式

答案。

## 输入输出样例 #1

### 输入 #1

```
6
5 3 1 9 2 4
```

### 输出 #1

```
4
```

## 说明/提示

$40\%$ 的数据保证 $n \leq 3000$。

$80\%$ 的数据保证 $n \leq 10^5$。

所有数据保证 $1 \leq n \leq 10^7$，$1 \leq a_i \leq 10^9$。

:::

:::info[B | 序列]

## 题目描述

已知长度为 $n$ 的序列 $a$ 满足

- $\forall 1 \leq i \leq n,1 \leq a_i \leq m$
- $\forall 1 \leq i < n,\left\lvert a_{i}-a_{i+1} \right\rvert \geq k$

求这样的序列 $a$ 的个数 $\bmod$ $998244353$ 的值。

## 输入格式

仅一行，三个整数 $n,m,k$。

## 输出格式

答案。

## 输入输出样例 #1

### 输入 #1

```
2 3 1
```

### 输出 #1

```
6
```

## 说明/提示

**样例解释**

$(1,2),(1,3),(2,1),(2,3),(3,1),(3,3)$ 是满足条件的序列，共 $6$ 组。

**数据范围**

所有数据保证 $1 \leq n \leq 1000,1 \leq m \leq 5000,0 \leq k < m$。

:::

:::info[D | 字符串]

## 题目描述

字符串 $s$ 满足

- 仅包含大小写字母和数字。
- 每个字符互不相同。
- 相邻的字符的类型（大写字母，小写字母或数字）不相同。
- 恰有 $x$ 个大写字母，$y$ 个小写字母和 $z$ 个数字。

求满足条件的 $s$ 的数量 $\bmod$ $10^9+7$ 的结果。

## 输入格式

本题单个测试点内有多组数据。

第一行：一个整数 $G$，表示数据组数。

接下来 $G$ 行，每行三个整数 $x_i,y_i,z_i$。

## 输出格式

$G$ 行，每行一个答案。

## 输入输出样例 #1

### 输入 #1

```
请输入文本
```

### 输出 #1

```
请输入文本
```

## 说明/提示

$30\%$ 的数据保证 $x_i,y_i,z_i \leq 4$。

所有数据保证 $1 \leq G \leq 5,0 \leq x_i,y_i \leq 26,0 \leq z_i \leq 10$。

给出长度为 $n$ 的 $1 \dots n$ 的排列 $a$ 和 $m$ 组数对 $(c_i,d_i)$。你可以进行若干次操作，每次操作需要选择一个 $i$，然后交换 $a_{c_i}$ 和 $a_{d_i}$。请你求出在若干次操作后，满足 $1 \leq i \leq n$ 且 $a_i=i$ 的 $i$ 的数量的最大值。

## 输入格式

第一行：两个整数 $n,m$。

### 输入 #1

```
3 2
3 2 1

2 3
```

### 输出 #1


## 说明/提示

所有数据保证 $1 \leq n,m \leq 2 \times 10^5,1 \leq c_i,d_i \leq n,\forall 1 \leq i < j \leq m,(c_i,d_i) \neq (c_j,d_j)$。

## 题目描述

给定长度为 $n$ 的 $1 \sim n$ 的排列 $a$ 和字符串 $s$，$s_i \in \{\text{B,R}\}$。请你判断是否存在一个 $1 \sim n$ 的排列 $b$，使得

$$
b_i
\begin{cases}
  \leq a_i  & s_i = \text{B} \\
  \geq a_i   & s_i = \text{R} \\
\end{cases}
$$

有则输出 `YES`，没有则输出 `NO`。

## 输入格式

单个测试点内有多组测试数据。

第一行：一个整数 $T$，表示数据组数。

接下来有 $T$ 组数据，每组数据格式如下

第一行：一个整数 $n$。

接下来一行：$n$ 个整数 $a_i$。

接下来一行：一个字符串 $s$。

## 输出格式

输出共 $T$ 行，每行一个 `YES` 或 `NO`。

## 说明/提示

对于所有数据，保证 $1 \leq T \leq 10^5,1 \leq \sum n \leq  2 \times 10^5,s_i \in \{\text{B,R}\}$。
:::

## 题目描述

给定长度为 $n$ 的序列 $a,b$，求最小的 $k$ 使得存在 $s \in \{1,2,\dots,n\}$ 满足 $\sum_{j \in s} a_j+kb_j \geq m$ 且 $\min_{j \in s} a_j+kb_j \geq l$。

## 输入格式

第一行：三个整数 $n,m,l$。

接下来一行：$n$ 个整数 $a_i$。

接下来一行：$n$ 个整数 $b_i$。

## 输出格式

答案。

## 说明/提示

对于所有数据，保证 $1 \leq n \leq 2 \times 10^5,1 \leq a_i,b_i \leq 10^9,1 \leq m,l \leq 10^{18}$。
:::

:::info[D | Match]

## 题目背景

原题 [Luogu P4059](https://www.luogu.com.cn/problem/P4059)。

## 题目描述

给定长度分别为 $n,m$ 的字符串 $a,b$，两个字符串的字符集 $s=\{\text{A,T,G,C}\}$，你可以在 $a,b$ 内任意插入空格，但需要保证最终的字符串 $a,b$ 长度相同。你的目标是使得最终权值最大。权值的计算方法如下

- 假设最终 $a,b$ 的长度为 $o$，那么权值加上 $\sum_{i=1}^{o} \operatorname{dis}(a_i,b_i)$。

- 对于 $a,b$ 中的每个**极长的**连续空格段，假设这段空格的长度为 $k$，那么权值**减去** $A+B(k-1)$。

请你输出最大可能的权值。

## 输入格式

第一行：一个字符串 $a$。

第二行：一个字符串 $b$。

接下来 $4$ 行是一个 $4 \times 4$ 的整数矩阵，矩阵的第 $i$ 行 $j$ 列是一个整数，表示 $\operatorname{dis}(s_i,s_j)$。

最后一行：两个整数 $A,B$。

## 输出格式

答案。

## 输入输出样例 #1

### 输入 #1

```
ATGG
ATCC
5 -4 -4 -4 
-4 5 -4 -4 
-4 -4 5 -4 
-4 -4 -4 5 
2 1
```

### 输出 #1

```
4
```

## 说明/提示

对于所有数据，保证 $1 \leq n,m \leq n+m \leq 3000,-1000 \leq \operatorname{dis}(s_i,s_j) \leq 1000,1 \leq A < B \leq 1000,\forall 1 \leq i,j \leq 4,\operatorname{dis}(s_i,s_j)=\operatorname{dis}(s_j,s_i)$。
:::
