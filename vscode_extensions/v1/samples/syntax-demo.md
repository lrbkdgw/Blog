# Markdown 语法拓展 · 示例

使用 VS Code **内置 Markdown 预览**分屏打开这份文档（`Ctrl/⌘ + K V`）。右侧直接运行与博客相同的组件与样式；拖动变量时，正文、公式、表格与代码都应同步更新。

## 1. 交互展示框

::show_begin{二次函数}{a:Z=1[-5,5,1]; b:Q=0[-10,10,0.5]{faster_set}; name:S=星野[0,12]}
当 *&show(a)*&、*&show(b)*& 时，$a^2+b$ = *&hs(a^2+b)*&。

向下保留两位：&*floor(a^2+b,2)&*；向上保留两位：&*ceil(a^2+b,2)&*。

你好，*&show(name)*&。符号是 *&a:{-1,负一;0,零;1,正一}*&。
::show_end

要点：

- `*&show(变量名)*&` 输出当前变量。
- `*&hs(表达式)*&` 计算只含 `+ - * / ^ ()` 与数值变量的式子。
- `&*floor(数值,位数)&*` / `&*ceil(数值,位数)&*` 按位数向下 / 向上取整。
- `*&变量名:{键,内容;…}*&` 声明取值到展示内容的映射，未在标题里声明的变量会自动生成控件。
- 整数默认带滑动条；有理数要加 `{faster_set}` 才有滑动条；字符串的两个限制是最小、最大长度。

展示框里的替换等价于「把这段源码直接换成结果」，所以在表格、公式甚至代码块里都能用：

::show_begin{用在别处}{n:Z=3[1,9,1]}
| n | n² | n³ |
| :-: | :-: | :-: |
| *&show(n)*& | *&hs(n^2)*& | *&hs(n^3)*& |

$$
\sum_{i=1}^{*&show(n)*&} i = *&hs(n*(n+1)/2)*&
$$

```cpp
for (int i = 0; i < *&show(n)*&; ++i) solve(i);
```
::show_end

## 3. 表格与单元格合并

普通表格整体靠左，未指定对齐的列默认左对齐；指定的列对齐保留。

| 默认 | 左对齐 | 居中列 | 右对齐 |
| --- | :--- | :---: | ---: |
| 文本 | 文本 | 文本 | 123 |

### Tuack 表格（整体居中）

`<` 与左边的单元格合并，`^` 与上面的单元格合并。

::cute-table{tuack}

| 测试点 | 数据范围 | 分值 |
| :-: | :-: | :-: |
| 1 ~ 3 | $n \le 10$ | 30 |
| 4 ~ 6 | ^ | < |
| 7 ~ 10 | $n \le 10^5$ | 70 |

### 普通合并表格（整体靠左）

普通表格同样支持合并：

| 阶段 | 内容 | 备注 |
| --- | --- | --- |
| 预处理 | 读入 | 无 |
| ^ | 排序 | < |
| 求解 | 二分 | $O(n\log n)$ |

## 4. 文章开头排版指令（字体与背景）

在文章**最开头**（frontmatter 之后、第一段正文之前）可以写三条指令，强制本文的排版。指令行本身不会显示在正文里：

~~~markdown
::set-font[LXGW WenKai]
::set-code-font[Fira Code]
::set-background[1]
~~~

- `::set-font[字体名]`：正文字体；`::set-code-font[字体名]`：代码字体。两者都可以写多条，**越早出现的优先级越高**（后面的作回退），一条里也能用逗号分多个字体名。
- `::set-background[编号]`：阅读本文时的动态背景，`0` 无 · `1` 樱花 · `2` 粒子星链 · `3` 雪花 · `4` 暴雨 · `5` 竹林；写多条时第一个合法编号生效。
- 只有开头的指令有效，正文开始后再写只是普通文字；在代码围栏里展示语法不会被执行（本节的示例就是这样写的）。

在这里的内置预览中，字体指令会直接作用于预览正文（需本机装有该字体）；背景是博客网页的动态场景，预览里只移除指令行、不切换背景，到博客文章页打开本文即可看到效果。离开文章后恢复读者自己的字体与背景偏好，不会改掉已保存的设置。

## 5. 插入 LaTeX 符号

在 Markdown 编辑器中按 `Shift + ↑`（或从命令面板执行 **Markdown 语法拓展: 插入 LaTeX 符号…**），可用命令或中文别名搜索符号：搜「正负」或「加减」选到 `±` 对应的命令，搜「异或」能找到圆加符号。选中后符号插入光标处，需要参数的命令（如分数）会把光标放进第一个参数里。博客站内编辑器里是同一份符号目录、同一个快捷键。

## 6. 直角坐标系（ui-ccs）

使用 `::begin_ui-ccs` 与 `::end_ui-ccs` 绘制可拖拽平移、滚轮缩放的二维直角坐标系，支持描点、多点折线与关于 $x$ 的显式函数图像：

::begin_ui-ccs
create_point:(0,0);
create_point:(2,3),[color=#10b981];
create_line:(-3,-2),(0,1),(3,-1),[color=red];
create_line:(7*x^2+6*x+90*x^3);
::end_ui-ccs

## 7. 图论画布（ui-graph）

使用 `::begin_ui-graph[<附加项>]` 与 `::end_ui-graph` 绘制可拖拽平移、滚轮缩放的图论画布（`dag` 启用有向图；站内编辑器中可开启「调整模式」直接拖拽保存节点坐标）：

::begin_ui-graph[dag]
5
1 2 10
2 3 5
1 3 18
3 4 7
::end_ui-graph
