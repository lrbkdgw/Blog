# 星野笔记特殊语法 · 示例

把这份文档分屏预览（`Ctrl/⌘ + K V`），右侧应当出现可拖动的展示框、彩色折叠框和合并单元格的表格。

## 1. 交互展示框

::show_begin{二次函数}{a:Z=1[-5,5,1]; b:Q=0[-10,10,0.5]{faster_set}; name:S=星野[0,12]}
当 *&show(a)*&、*&show(b)*& 时，$a^2+b$ = *&hs(a^2+b)*&。

向下保留两位：&*floor(a^2+b,2)&*；向上保留两位：&*ceil(a^2+b,2)&*。

你好，*&show(name)*&。符号是 *&a:{-1,负一;0,零;1,正一}*&。
::show_end

要点：

- `*&show(变量名)*&` 输出当前变量。
- `*&hs(表达式)*&` 计算只含 `+ - * / ^ ()` 与数值变量的式子。
- `&*floor(数值,位数)&*` / `&*ceil(数值,位数)&*` 按位数向下 / 向上取整。
- `*&变量名:{键,内容;…}*&` 声明取值到展示内容的映射，未在标题里声明的变量会自动生成控件。
- 整数默认带滑动条；有理数要加 `{faster_set}` 才有滑动条；字符串的两个限制是最小、最大长度。

展示框里的替换等价于「把这段源码直接换成结果」，所以在表格、公式甚至代码块里都能用：

::show_begin{用在别处}{n:Z=3[1,9,1]}
| n | n² | n³ |
| :-: | :-: | :-: |
| *&show(n)*& | *&hs(n^2)*& | *&hs(n^3)*& |

$$\sum_{i=1}^{*&show(n)*&} i = *&hs(n*(n+1)/2)*&$$

```cpp
for (int i = 0; i < *&show(n)*&; ++i) solve(i);
```
::show_end

## 3. Tuack 表格与单元格合并

`<` 与左边的单元格合并，`^` 与上面的单元格合并。

::cute-table{tuack}

| 测试点 | 数据范围 | 分值 |
| :-: | :-: | :-: |
| 1 ~ 3 | $n \le 10$ | 30 |
| 4 ~ 6 | ^ | < |
| 7 ~ 10 | $n \le 10^5$ | 70 |

普通表格同样支持合并：

| 阶段 | 内容 | 备注 |
| :-: | :-: | :-: |
| 预处理 | 读入 | 无 |
| ^ | 排序 | < |
| 求解 | 二分 | $O(n\log n)$ |
