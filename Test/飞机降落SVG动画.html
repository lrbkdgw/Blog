✦ 技术实现

纯 SVG + CSS @keyframes，无外链、无 JS 即可循环播放。
飞机 translate + rotate 复合变换沿贝塞尔缓动下滑，stroke-dasharray 驱动跑道中线与尾迹流，filter + radialGradient 营造黄昏光晕与尾焰。

✦ 可交互说明

可直接保存为 .svg 独立使用；支持 暂停 / 重播 / 慢动作。
缩放无失真，适配深色背景与高分屏；二次开发仅需修改 #plane-group 的 flight 关键帧即可改下滑角与接地点。
